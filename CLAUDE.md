# Repo conventions

## Branch naming

New branches follow: `kelly/<feature-name>` (e.g. `kelly/live-demo-retry`) for a
specific feature or fix, or `kelly/update` for general/miscellaneous updates
that don't warrant a more specific name. Do not use the `claude/<random-slug>`
pattern for anything created after this rule was set.

Commits on those branches follow normal conventional messages (imperative,
concise summary line, body explaining why).
